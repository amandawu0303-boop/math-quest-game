# 小小算術探險隊

以 Phaser 4 製作的國小數學闖關遊戲。共有五關、每關三題；操控小探險家碰到答案球作答，答對加 10 分，答錯扣 5 分。

## 開始遊戲

在可連線至 CDN 的瀏覽器中直接開啟 `index.html`。若瀏覽器限制本機檔案載入，可在此資料夾啟動簡易網站伺服器：

```powershell
py -m http.server 8000
```

接著開啟 `http://localhost:8000`。

## 操作方式

- 電腦：方向鍵或 W、A、S、D 移動角色。
- 手機或平板：使用遊戲地圖下方的觸控方向鍵。
- 走到答案球上即可作答。答錯後答案球會重新排列，題目不會跳過。

遊戲載入 Phaser 4.2.1 與字型時需要網路連線。
